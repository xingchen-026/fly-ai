# Fly-AI 生存世界

用 **FlyWire 雄性果蝇中枢神经系统连接组**（mini 子集：2594 个神经元 / 76323 条突触）驱动的
二维无限生存世界。世界由噪声程序化生成，天气、野火、疫病、迁徙等事件按数值概率自然发生，
地表按生物群系生成多种生物与资源；一小群"幸存者"各自拥有独立连接组大脑，
通过 **奖励调制 STDP + 可学习解码层** 学习生存，死亡时由最优个体克隆变异诞生下一代。

```
二维无限世界（群系/资源/结构/生态/季节） ──203 维感知──> LIF 连接组(每个体一个大脑, R-STDP)
   ▲                                                        │ 8 组下行神经元
   │                                                        ▼
   └── 代谢/竞争/进化 <── 动作(移动/采集/饮水/捕猎/休息/生火/建造) <── 可学习解码层
```

## 快速开始

```powershell
uv sync                     # 创建 .venv 并安装依赖（缓存已指向项目内 .uv-cache）
uv run python main.py       # 打开实时窗口（默认 3 个幸存者）
uv run fly-ai               # 等价入口

# 无头跑 8000 tick（约 33 天）并写 CSV 日志
uv run python main.py --headless --ticks 8000 --seed 1 --log logs/run1.csv

# 单个体快速模式（比 3 个体快约 4 倍）
uv run python main.py --headless --ticks 8000 --set population.size=1

# 关掉某种危险生物 / 调整参数
uv run python main.py --set ecology.species.wasp.enabled=false --set neural.plasticity.neuromod.lr=0.5
```

窗口按键：`ESC/Q` 退出 · `SPACE` 暂停 · `R` 焦点个体重生 · `1..9` 切换焦点个体 ·
`+/-` 1/2/4/8 倍速 · `TAB` 显示/隐藏连接组热力图。

> Windows 控制台中文乱码时执行 `chcp 65001` 或使用 Windows Terminal。
> `uv.toml` 已把 uv 缓存目录设到项目内 `.uv-cache`（默认用户缓存目录可能无权限）。

界面（`uv run python tools/smoke_render.py` 生成 `logs/render_test.png`）：
左侧 65×65 地图（群系、浆果/蘑菇/毒浆果/木材/石料、营火与庇护所、野火、疫病、
猎物/天敌/伏击者/毒虫/萤火虫、多个幸存者与焦点白环、夜晚灯笼光晕）；
右侧为**连接组放电热力图 + 学习状态行（DA / 突触Δ / 资格迹 / 解码漂移）**、
8 组下行神经元动作得分、生理与网络历史曲线（含多巴胺曲线）、生存状态条（含毒素、背包、建筑）、
事件日志与物种统计。

> → `body-neurotransmitters-*.feather`）。

**mini 子集的关键事实**：80 个感光细胞 R1-6 在子集内平均出度只有 0.1 条突触，而 1314 个下行
神经元（DN）几乎瓜分了全部 76323 条边（平均每个 DN 出 57 / 入 57）。因此该子集实质是一个
**DN 递归网络**，被当作固定结构的"储层"使用：从 DN 中固定随机选 160 个接收 203 维世界特征，
其余 DN 均分 8 组，组平均放电率经 z-score 后送入 8×8 可学习解码层；
1280 个视叶细胞（子集内几乎无连接）只参与状态演化。原始数据加载有进程内缓存，
重复构建网络（多种群/实验）不再重复读盘。

### 神经动力学

| 项目 | 设置 |
|---|---|
| 神经元模型 | LIF：`v += dt/τ_m*(-(v-v_rest) + gain·I_syn + I_ext) + ξ`，τ_m=20 ms，dt=1 ms |
| 每游戏 tick | 8 个神经步（8 ms）；决策每 4 tick 一次 |
| 阈值/复位/不应期 | -50 mV / -70 mV / 2 ms；噪声 σ=2.05（均匀分布，方差匹配） |
| 突触权重 | `突触数^0.6` → 按中位总输入归一化到 30 → 按**突触前递质**定符号 |
| 递质符号 | ACh +1.0、谷氨酸 +0.8、GABA -1.0、组胺 -1.0、5-HT/多巴胺/章鱼胺 +0.5 |
| E/I 平衡 | 抑制性总权重占总权重 **30%** |
| 自稳态 | 全局增益按 DN 平均放电率目标 3 Hz 调节（0.2~5.0，实测 ~1.5~3.8） |
| 单步成本 | ~46 µs（CSR matvec，76323 nnz）；单个大脑每 tick ≈1.5 ms |

## 学习：奖励调制 STDP + 神经调质

（配置 `neural.plasticity`，可整体/分项关闭）

1. **STDP 资格迹**：突触前/后脉冲分别产生下调/上调倾向，迹 τ=20 ms，资格迹 τ=900 ms；
   以 `stride_ms=6` 分步更新（振幅等比缩放，等价近似），资格迹只维护 CSR 布局并按步同步转置矩阵。
   默认只改兴奋性突触，权重夹在 `[w_floor, 3×w_ref]`。
2. **神经调质（多巴胺式 DA）**：由行为结果生成 DA ∈ [-1,1] —— 吃浆果/蘑菇 +0.6×需求比例、
   饮水 +0.35×需求比例、捕猎 +1.0×收益比例、拾取材料 +0.04、生火/建造 +0.3~0.4、
   受伤/火焰/疫病/毒素/失温按伤害量负值、状态良好 +0.01、死亡 -1.0。
   奖励按**真实需求**缩放（吃饱后喝水不再给奖励），避免刷奖励病态策略。
3. **权重更新**：`Δw = lr·DA·eligibility`（lr=0.25），轻微遗忘 + **突触稳态缩放**
   （每 20 tick 把每个神经元兴奋性输入总预算缓慢拉回初始值，允许突触间重新分配）。
4. **可学习解码层**：`R[:, a] += lr_r·DA·z`（lr_r=0.015）并向单位阵衰减，限幅 ±2.5。

消融（`tools/learning_ablation.py`，单个体、**关闭进化**以隔离可塑性；原始输出
`logs/ablation_multiseed.txt`、`logs/ablation_long.txt`）：

**短程 4 seeds × 3000 tick（≈12 天）**

| 设置 | 死亡 | 平均HP | 进食 | 捕猎 | 被咬 | 突触Δw | 解码漂移 |
|---|---|---|---|---|---|---|---|
| A 无可塑性 | 1.0±1.0 | 66.0±22.4 | 3.0±1.6 | 0.8 | 18.2±13.0 | 0.00% | 0.000 |
| B 仅 R-STDP | 1.2±0.8 | 60.1±23.9 | 4.8±1.1 | 0.8 | 26.8±15.5 | 3.74% | 0.000 |
| C R-STDP+解码（默认） | **0.8±0.4** | **75.2±34.2** | **5.2±1.1** | **1.8** | **18.0±11.0** | 4.00% | 0.002 |

**长程 2 seeds × 8000 tick（≈33 天）**

| 设置 | 死亡 | 平均HP | 平均能量 | 进食 | 捕猎 | 被咬 |
|---|---|---|---|---|---|---|
| A 无可塑性 | 1.5±1.5 | 97.3±0.2 | 90.5±1.3 | 14.5±3.5 | 1.5 | 16.0±16.0 |
| B 仅 R-STDP | 2.0±1.0 | 73.2±13.1 | 91.4±0.8 | 17.0±6.0 | 2.0 | 40.5±27.5 |
| C R-STDP+解码（默认） | 2.0±1.0 | 69.9±22.2 | 72.5±17.1 | 14.0±3.0 | 2.5 | 48.0±25.0 |

结论（诚实版）：短程内默认配置 C 的平均 HP / 进食 / 捕猎最好，B（只改突触、解码固定）
被咬显著更多——**STDP 会打乱任意初始化的解码映射**，可学习解码层 + 突触稳态能把它拉回来，
这是最可靠的机制性结论。长程只有 2 个种子且方差极大（C 被咬 48±25、A 平均 HP 97），
**不能据此宣称可塑性带来稳定生存优势**；要判定生存收益，请用 `tools/experiments.py`
跑更多种子（例如 `--seeds 1,2,3,4,5,6,7,8 --ticks 8000`）。突触权重始终被稳态缩放与
`[w_floor, 3×w_ref]` 夹住（长程 Δw 约 4~6%），不会发散。

## 种群与进化

配置 `population`。默认 **3 个幸存者**共用同一张无限地图：

- 每个个体有**独立的大脑**（自己的结构种子 → 不同的输入组/动作分组/编码器）与独立的
  本能/探索/网络权重偏好（trait），因此行为天然分化；
- 浆果、蘑菇、木材、石料、猎物、建筑位置都是**共享资源** → 直接竞争；
- 每 tick 累计适应度 `fitness += 截断奖励 + 0.002`（生存与获得奖励都会累积）；
- **死亡即进化**：个体死亡后，从存活个体中选出适应度最高者，克隆其连接组权重、解码层与
  trait（高斯变异：0.4% 突触 × σ=10%、解码层 σ=10%、trait σ=0.06），在附近重生为下一代；
- 无进化模式（`population.evolution.enabled=false`）时同一大脑原地苏醒。

界面按 `1..9` 切换焦点个体，右侧面板显示焦点大脑的网络活动、适应度排名与世代数。
单个体运行更快（523 tick/s），多种群更慢但能看到进化（见性能表）。

## 世界生成

- **地形**：两层 fBm 值噪声 → 7 种群系。实测占比：深水 10.3%、浅水 7.7%、沙地 5.7%、
  草地 36.9%、森林 31.8%、岩石 2.1%、沼泽 5.6%。
- **无限地图**：地形/资源是 `(x,y,seed)` 的纯函数，按 32×32 区块惰性生成 + LRU 缓存；
  瞬态状态（采空、火、灰、疫病、爆发、建筑）存稀疏字典。
- **气候**：240 tick = 1 天，3 天 = 1 季；温度 = 21℃ + 季节 + 昼夜 ±5℃ + 群系修正 + 天气；
  森林保温 1.55 倍、岩石 1.9 倍、营火周围 +9℃。

## 智能体

**203 维感知** = 5×5 视野 ×7 通道（水 / 可食植被 / 深水阻挡 / 食物 / 危险 / 毒浆果 / 材料）
+ 14 维内部状态（HP、能量、口渴、体温、清醒、光照、脚下食物、可否饮水、毒素、三种背包、
营火临近、庇护所）
+ 14 维方向线索（最近食物/水/天敌/猎物/庇护所/危险/材料）。

**8 个动作**：上/下/左/右、采集-进食-饮水-捕猎、休息、生火/添柴、搭建庇护所。
动作得分 = `本能 + 0.65×网络解码得分 + 粘滞 + 探索噪声`（每 4 tick 决策一次）。
材料不足或位置不满足时，不可用的建造动作会被**动作掩码**屏蔽（分数 -50），
避免把体力浪费在必然失败的动作上；实测无效建造从每 2500 tick 数十次降到 0。

本能：饿了找浆果/蘑菇并进食、渴了找水、累了休息、见天敌反向逃、见火/疫病立即远离
（移动时也拒绝踏入危险格）、低温找柴石生火或搭庇护所、体温低找森林/岩石、
有猎物且能量不足时追猎、中毒时保存体力；营火旁会主动休息。

代谢：能量/口渴/疲劳按 tick 衰减；体温向环境温度弛豫（庇护所内保温 ×2）；饥饿、脱水、
失温、中暑、火焰、疫病、动物伤害与毒素扣血；状态良好时缓慢回血；死亡后进入进化流程。

## 性能（本机实测，无头模式）

| 种群规模 | tick/s | 说明 |
|---|---|---|
| 1 个体 | ~520 | 快速实验推荐 |
| 2 个体 | ~160 | |
| 3 个体（默认） | ~110 | 1×~4× 窗口流畅，8× 接近上限 |
| 4 个体 | ~85 | |

单 tick 组成：每个大脑 8 神经步 ≈1.5 ms（含 STDP 资格迹）、权重同步每 2 tick 一次、
突触稳态每 20 tick 一次、共享世界（生态 52+ 生物、事件、资源）≈1.5 ms。
连接组原始数据有进程内缓存，实验器重复构造 Simulation 只读一次盘。

## 已知妥协

1. **不是全脑仿真**：mini 子集缺少大量中间神经元，输入/输出映射是工程妥协；
   它提供的是"行为由真实连接组动力学 + 可塑性调制"的可解释基线。
2. **学习收益尚未在统计上确立**：短程（约 12 天）内 STDP 会打乱任意解码映射
   （B 组被咬显著更多），可学习解码层 + 突触稳态能把它拉回来；长程 2 个种子方差极大，
   不能证明稳定的生存优势。机制层面可塑性确实生效（权重按 DA 改变、解码漂移可测），
   要做统计结论请用 `tools/experiments.py` 跑更多种子。
3. **进化压力有限**：默认 3 个体、突变率 0.4%，几十代内主要是行为多样性与个体适应度差异，
   还不足以看到明显的形态分化；把 `population.size` 与突变率调大可以加速选择。
   默认多种群在 10 天左右通常出现 0~1 次死亡→进化事件，3/3 存活。
4. **性能与种群规模线性相关**：每个大脑都是 2594 神经元 LIF + STDP，3 个体约 110 tick/s；
   想要更快可以 `--set population.size=1` 或减少 `time.neural_steps_per_tick`。
5. **奖励塑形**：奖励按需求比例缩放，避免刷奖励；毒浆果等风险行为由本能只在高需求时触发。

## 故障排查

- **`uv` 缓存权限错误**：项目已提供 `uv.toml`；仍失败可设 `UV_CACHE_DIR` 到可写目录。
- **`fly-ai` 提示 `No module named 'src'`**：`uv sync --reinstall-package fly-ai-survival`。
- **无显示器/远程会话**：设 `SDL_VIDEODRIVER=dummy` 可跑无头渲染测试。
- **多进程实验报 `WinError 5`**：实验器会自动回退串行；也可显式 `--jobs 1`。
- **中文乱码**：`chcp 65001` 或使用 Windows Terminal / VS Code 终端。
